# АИС Техник-Программист v6.0 - Модульная версия

## Структура проекта

```
/workspace/
├── main.py                 # Главный файл приложения (точка входа)
├── README_STRUCTURE.md     # Этот файл
└── modules/                # Пакет модулей
    ├── __init__.py         # Инициализация пакета, экспорт классов
    ├── database.py         # Работа с базой данных (класс DB)
    ├── equipment.py        # Вкладка: ПК/Ноутбуки/Принтеры
    ├── network.py          # Вкладка: Сетевое оборудование
    ├── maintenance.py      # Вкладка: Журнал обслуживания
    ├── stock.py            # Вкладка: Склад
    ├── cartridges.py       # Вкладка: Картриджи
    ├── reports.py          # Вкладка: Отчёты
    └── contract.py         # Вкладка: Контракт
```

## Запуск приложения

```bash
python main.py
```

## Описание модулей

### `database.py`
Класс `DB` - все операции с SQLite базой данных:
- Создание таблиц (equipment, network_equipment, cartridges, maintenance, stock, и т.д.)
- CRUD операции для всех сущностей
- Отчёты и выборки
- История изменений статусов

### `equipment.py`
Класс `EquipmentTab` - управление оборудованием:
- Добавление/редактирование/удаление ПК, ноутбуков, принтеров, МФУ
- Изменение статуса оборудования
- Установка техники после ремонта/сервиса
- Добавление ПО для компьютеров

### `network.py`
Класс `NetworkTab` - сетевое оборудование:
- Серверы, коммутаторы, маршрутизаторы, WiFi-роутеры, серверные шкафы
- Учёт портов, пропускной способности, информации о стойках

### `maintenance.py`
Класс `MaintenanceTab` - журнал работ:
- Запись о работах (диагностика, ремонт, ТО, заправка и т.д.)
- Учёт внешних сервисов и стоимости
- Приём техники из сервиса
- Установка картриджей после заправки

### `stock.py`
Класс `StockTab` - склад:
- Приход/расход товаров
- Добавление новых позиций
- Удаление товаров

### `cartridges.py`
Класс `CartridgesTab` - управление картриджами:
- Полный цикл жизни картриджа (В работе → К заправке → На заправке → С заправки → В работе)
- Выдача запасных картриджей
- Автоматическая замена рабочего картриджа на запасной
- История операций с картриджами

### `reports.py`
Класс `ReportsTab` - отчёты:
- Инвентаризация оборудования
- Инвентаризация сетевого оборудования
- Статистика по типам техники
- Статусы картриджей
- История изменений статусов

### `contract.py`
Класс `ContractTab` - мониторинг контракта:
- Отслеживание лимита расходов (50000 руб/месяц)
- Список работ по внешнему сервису
- Предупреждение о превышении лимита

## Преимущества модульной структуры

1. **Лёгкость редактирования** - каждый модуль отвечает за свою функциональность
2. **Читаемость** - код разбит на логические блоки по 100-350 строк
3. **Переиспользование** - модули можно использовать в других проектах
4. **Тестирование** - проще тестировать отдельные компоненты
5. **Масштабируемость** - легко добавить новую вкладку/функциональность

## Как добавить новый модуль

1. Создать файл в папке `modules/` (например, `users.py`)
2. Добавить класс с логикой вкладки
3. Добавить импорт в `modules/__init__.py`
4. Подключить в `main.py`

## Пример импорта в main.py

```python
from modules import DB, EquipmentTab, NetworkTab, ...
```
